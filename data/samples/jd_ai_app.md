# AI 应用开发实习生（LLM 应用方向）

公司：杭州云栈智能科技有限公司（虚构）　部门：AI 应用工程组
工作地点：杭州 · 每周到岗至少 4 天

## 岗位职责

1. 参与公司大模型应用（检索增强问答、简历解析）的需求分析与功能开发；
2. 使用 Python 编写后端服务，负责接口开发、数据处理与简单部署；
3. 参与 Prompt 工程与效果评测，持续迭代回答质量；
4. 与产品、算法同学协作，输出可复用的技术文档。

## 任职要求

1. 本科及以上学历，计算机相关专业，2027 届毕业生优先；
2. 熟悉 Python，具备良好的编码习惯与调试能力；
3. 熟悉 FastAPI 或其他 Python Web 框架，能独立写 RESTful 接口；
4. 熟悉 SQL，能写多表关联查询；
5. 掌握 Git 基本工作流（分支、合并、Code Review）；
6. 至少实习 3 个月，每周到岗 4 天以上。

## 加分项

1. 了解 RAG（检索增强生成）与向量检索，做过知识库问答项目；
2. 了解 Prompt 工程，有结构化输出（JSON）调试经验；
3. 了解 Docker，能用容器化方式部署服务；
4. 有 LangChain 使用经验者优先；
5. 了解高并发场景下的性能优化者加分。
